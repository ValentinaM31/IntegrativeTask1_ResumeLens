`models/` contains FST formalizations, tables and graphs; `automata/` contains the profile models. `poster/` contains a partial A2 SVG covering extraction and normalization, without recognition, DSL or UI results.

Documentation, comments and program messages are in English. Spanish quoted inputs and regex vocabulary are retained to verify bilingual support. The academic AI-interaction record is kept outside the code and must be submitted as independent evidence.
